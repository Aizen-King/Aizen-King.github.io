YOLOV1

发表于2026-07-21|更新于2026-10-02|learning
|浏览量:

网络结构

![[YOLOV1.png|1284]]

  • Input Image：输入448×448×3 的图像，像素是 448×448，通道为 3
  • Back bone 网络：若干的卷积层，一般的卷积网络，结构省略，并非关注重点
  • Fully connected：通过全连接网络输出7×7×30 的Tensor (张量)

7×7×30 的 Tensor 在训练和推理阶段分别起着什么作用

  • 训练阶段：7×7×30 的Tensor 作为网络的输出，目的是通过和输入图像的标签建立联系（即通过损失函数计算损失）来优化网络的权重，从而使得预测能够更加接近真实的标签。
  • 推理阶段：而关注的重点是这个7×7×30的 tensor是如何表示输出的边界框和类别的，因为在推理阶段，我们希望网络的输出就是一个一个效果很好的边界框，同时这个边界框带有框内物体的类别信息

数据标注

YOLO 算法将目标检测视为一个回归问题，将输入图像划分为 s×s 的网格，即 grid cell，对于 YOLOv 1 而言，s 的值为 7
每个网格会有标签向量[x, y, w, h, Objectness, class 1, class 2,……]

  • X，Y 是物体中心点相对于网格的坐标，网格左上角是（0,0），右下角是（1,1）
  • W，H 是物体的边界框相对于整个输入图像的宽度和高度
  • Objectness 是物体存在的概率，如果物体的中心点处于网格中，那么该网格的 Objectness 就是 1，否则为 0
  • Class 是物体的类别，会存在多个 Class，如果某个 Class 是 1，另外的所有 Class 为 0

输出张量

对于 YOLOv 1 的 7×7×30 的 tensor，可以视为 49 个 1×1×30 的 tensor 堆叠而成
![[YOLOV1-1.png|925]]

  • 每个1×1×30 的 tensor 会预测 B 个 bounding box(边界框)，对于 YOLOv 1 而言，B=2（图中蓝色和绿色标注为 2 个 bounding box）
  • Bounding box 包含五个值：x, y, w, h, Pr (Object)×IOU|truthpred
    • x, y, w, h 就是数据标注中标签向量的位置元素
    • Pr (Object)×IOU|truthpred是置信度(Confidence Score) 的计算公式，IOU|truthpred的值为预测框和真实框的交集 : 预测框和真实框的并集, Pr (Object)表示网格中是否存在物体的概率，存在为 1，反之为 0，所以如果网格中没有物体，那么置信度为 0，反之为 IOU|truthpred的值
  • 同时，每个网格会预测一系列的类别概率，Pr (Classi|Object)，对于 YOLOv 1 会预测 20 个值（图中白色标注）

训练阶段

具体来说，就是将输出的 7×7×30 的 tensor和训练数据的 ground truth 进行一个比对，计算一个损失，然后通过反向传播来更新网络的参数以获得更好的预测效果
![[YOLOV1-2.png|576]]

  • 在训练阶段，通过前向传播，模型会给出两个 box，即预测框，选择与 groundtruth 交并比值更大的一个 box

![[YOLOV1-3.png|1082]]

  • 再通过损失函数计算该 box 和 ground truth 之间的损失，通过损失反向传播，更新参数
  • 边界框坐标回归损失：只对“有物体的格子”且“选定的预测框”计算，中心点坐标的损失=真实的 x 和预测的 x 的差的平方 + 真实的 y 和预测的 y 的差的平方，边界框的损失=真实的sqrt (w)与预测的sqrt (w)的差的平方+真实的 sqrt (h) 与预测的 sqrt (h) 的差的平方，然后乘上一个大的权重（通常为 5）
  • 置信度损失：分为两项，对于选定的 box，计算真实置信度 − 预测置信度，再平方；对于淘汰的 box，计算（预测置信度 − 0）的平方，但这里会乘上一个很小的权重（比如 0.5），避免它主导损失
  • 类别概率损失：只对有物体的格子计算（不管哪个框） ，对每个类别 c，计算（预测概率 − 真实概率）的平方，然后求和，这个损失在一个格子中只做一次，而不是每个框都做。

推理阶段

![[YOLOV1-4.png|1155]]

  • 图 1：每一个网格会输出两个边界框，也就是说会得到 7×7×2 =98 个边界框，每一个边界框都有其置信度，用线框表示，线框越粗，置信度越大
  • 图 2：通过将每一个网格置信度与类别概率相乘得到该网格是第 i 类的全概率，进而得到概率图
  • 图 3：将图 1 和图 2结合起来得到彩色线框图
  • 图 4：通过非极大值抑制技术(NMS)，先算每个框的类别置信度得分 （每个框的置信度与 20 个类别向量相乘得到全概率向量）→ 排序 → 选某个类的最高分框 → 删掉与其重叠过多的框 → 重复对不同类进行这个过程，直到留下最独特、最可信的框集合

    在某个类的单一过程中可能在最后会保留多个框，但是在对所有类遍历之后，每个类的每一个对象只会剩下一个框

总结

训练阶段：预测 98 个边界框 → 选择与真实框交并集最大的框作为负责框→ 计算损失，进行拟合 →反向传播修正网络参数
推理阶段：预测 98 个边界框 → 利用 NMS 技术逐类移除多余的边界框 → 留下每个类每个对象概率最大的边界框

训练 = 用数据“调参”，让网络学会映射关系
推理 = 用调好的参数，对新数据直接做前向计算，得到检测结果
结构固定，参数可变（训练时）→ 参数固定（推理时）

缺点

  1. 处理小而密集的物体表现不好，太小的检测不出来；对于物体较多的情况也无法检测，YOLOv 1 最多检测 49 个物体
  2. YOLOv 1 面对太多物体类别时也无法检测，YOLOv 1 至多只能检测 20 个类别
  3. YOLOv 1 对于不常见的物体横纵比表现不佳，数据集没有覆盖到，那么无法给出理想的边界框预测
  4. YOLOv 1 相较于比较先进的两阶段方法（R-CNN 家族），速度快，但精度较低
